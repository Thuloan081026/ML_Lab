# Kế hoạch Lab 2

1. Khám phá dữ liệu giao dịch thương mại điện tử.
2. Làm sạch dữ liệu và kiểm tra giá trị thiếu, dòng trùng.
3. Trích xuất đặc trưng ngày mua và mã hóa biến phân loại.
4. Chia dữ liệu theo thứ tự thời gian để tránh rò rỉ dữ liệu.
5. Huấn luyện hồi quy tuyến tính, cây quyết định và học trực tuyến.
6. Đánh giá bằng MAE, RMSE và lưu model triển khai.
7. Kiểm tra dự đoán qua API Flask.
